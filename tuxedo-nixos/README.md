# NixOS configuration for "tuxedo-nixos"

Desktop PC (TUXEDO hardware, Intel CPU, NVIDIA RTX 4070 Super), hostname
`tuxedo-nixos`, user `rvdveldt`. Dual-boot: NixOS replaces the former
TuxedoOS/Ubuntu partition; the existing Windows installation and the
existing EFI System Partition (ESP) are kept and chain-loaded via GRUB.

Software and services are shared with the MacBook/VM configuration
(`../mbp-m1-nixos`); hardware-specific parts (bootloader, kernel, Parallels,
Apple keyboard) are not copied from there.

## Files

| File | Purpose |
|------|---------|
| `configuration.nix` | Main system configuration (edited by hand) |
| `hardware-configuration.nix` | Generated by `nixos-generate-config`, do not edit |

## System settings

- **Bootloader:** GRUB (not systemd-boot), re-uses the existing ESP at
  `/boot/efi`. `useOSProber = true` detects Windows and adds it to the GRUB
  menu.
- **Kernel:** default NixOS (LTS) kernel, via `pkgs.linuxPackages`. The
  newest kernel (`linuxPackages_latest`) is too new for the NVIDIA driver and
  made the `nvidia-open` module fail to build.
- **Desktop:** KDE Plasma 6 on Wayland (SDDM).
- **GPU:** NVIDIA RTX 4070 Super, open kernel modules
  (`hardware.nvidia.open = true`), `nixpkgs.config.allowUnfree = true`.
- **TUXEDO hardware control:** `hardware.tuxedo-rs` (Rust reimplementation of
  TUXEDO Control Center; the original Electron app isn't packaged in
  nixpkgs) with `tailor-gui` as the TCC GUI alternative.
- **Time:** `Europe/Amsterdam`, hardware clock kept in local time (same as
  Windows, so the clock doesn't shift between OSes).
- **Locale:** `nl_NL.UTF-8` with all `LC_*` settings, `en_US.UTF-8` generated
  as fallback. Keyboard layout `us`.
- **Printing:** CUPS enabled.
- **Sound:** PipeWire (with ALSA, 32-bit ALSA and PulseAudio support).
- **Shell:** zsh with Oh My Zsh (theme `agnoster`, plugins `git`, `sudo`,
  `docker`), set as the login shell for `rvdveldt`.
- **nix-ld:** enabled, so prebuilt dynamically linked Linux binaries run.
  Needed for the Claude Code VS Code extension.
- **Nix flakes:** enabled (`nix-command` and `flakes` experimental features).

## ODBC (LibreOffice Base to MySQL/MariaDB on the Synology)

The MariaDB ODBC driver is registered by hand in `/etc/odbcinst.ini` under
`[MariaDB]`, because the generic `environment.unixODBCDrivers.mariadb`
option points to `lib/libmaodbc.so` while the library actually lives in
`lib/mariadb/libmaodbc.so`. The driver also can't find its own
`libmariadb.so.3` next to it, so `patchelf --add-rpath $out/lib/mariadb` is
added via `overrideAttrs`; this rebuilds the driver locally on the first
`nixos-rebuild switch`. The same driver works for MySQL servers.

Test from a terminal: `isql -v MariaDB <db-user> <password>`.

## Network: Samba + discovery

- **Samba server:** share `shared` (`/home/rvdveldt/shared`), user
  `rvdveldt` only, no guest access. Firewall opened automatically.
- **Samba-wsdd (WS-Discovery):** makes the share visible from Windows.
- **Avahi (mDNS):** lets the Synology be found by name and resolves
  `*.local` hostnames in Dolphin.
- **Firewall:** UDP 3702 (WS-Discovery) opened explicitly for KDE's SMB
  discovery, on top of what `openFirewall = true` already opens for Samba
  and Avahi.

After the first rebuild, set a Samba password once (separate from the login
password):

```bash
sudo smbpasswd -a rvdveldt
```

## Apply

```bash
sudo cp configuration.nix /etc/nixos/configuration.nix
sudo nixos-rebuild switch
```

Set the user password after the initial install (before first login):

```bash
nixos-enter --root /mnt -c 'passwd rvdveldt'
```

## Notes

- `system.stateVersion = "26.05"` must not be changed after the initial
  install.
- `networking.networkmanager.enable` must be defined only once; a duplicate
  definition previously caused a `nixos-install` error.
